* Using this configuration
This file is the source of truth for the configuration loader. Each section explains a part of the setup and loads its implementation from =lisp/=. Edit those Lisp files for implementation changes and this document for imports and explanations.

Doom's =:config literate= module tangles the source blocks into =config.el= during =doom sync= and when saving this document once the module is active. Do not edit the generated =config.el= directly. Tangling updates the file on disk; restart Emacs to apply configuration changes to the running session.

The imports below run in document order. Keep the macOS native compilation setup first, and set the Org directory before loading any code that needs Org.

Custom commands intended for =M-x= or keybindings use =my/=. Internal helpers, hooks and advice use =my--=; custom variables use =my-=. Internal modes and their associated keymaps keep the shared =my--= prefix so Emacs can derive their related names consistently.

#+begin_src emacs-lisp
;;; $DOOMDIR/config.el -*- lexical-binding: t; -*-
;; Generated from config.org. Edit config.org or the files under lisp/ instead.
#+end_src

* macOS
[[file:lisp/macos-config.el][macos-config.el]] discovers the active macOS SDK so native compilation can find libSystem without a fixed SDK path. It also configures Option as Meta and Command as Super. The SDK setup is guarded so it only runs on macOS.

#+begin_src emacs-lisp
(load! "lisp/macos-config")
#+end_src

* Appearance
[[file:lisp/appearance-config.el][appearance-config.el]] sets the theme, fonts, relative line numbers, font zoom steps and frame appearance. Package-specific window centring remains in the separate Olivetti configuration.

#+begin_src emacs-lisp
(load! "lisp/appearance-config")
#+end_src

* Text layout and line length
[[file:lisp/text-layout-config.el][text-layout-config.el]] replaces the vertical column guide with a theme-aware background tint on excess source columns in code. The default code limit is 80, Python uses 88, and Rust uses 100. Org and Markdown prose, terminals and generated buffers such as Magit and help are excluded from overflow highlighting.

Org and Markdown use visual wrapping with automatic hard filling disabled. Keep each prose paragraph on one source line, with blank lines between paragraphs; the display wraps to the available width. Source lines have no enforced length limit. =M-q= remains available for deliberately hard-wrapping a paragraph at =fill-column= (100 by default for prose), but is not needed for normal writing. Code and literal blocks retain their source line breaks. Code files remain unwrapped and use their formatter. Project-specific =fill-column= values in =.dir-locals.el= override the defaults; code highlighting follows =fill-column=. Formatter settings remain independent.

#+begin_src emacs-lisp
(load! "lisp/text-layout-config")
#+end_src

* Interface spacing
[[file:lisp/spacing-config.el][spacing-config.el]] enables spacious-padding by default, with modest interface spacing and thin visible dividers between split windows. Use =SPC t P= (capital =P=) to toggle it. Olivetti retains its own window fringes and can be toggled separately with =SPC t o=.

#+begin_src emacs-lisp
(load! "lisp/spacing-config")
#+end_src

* Org
[[file:lisp/org-config.el][org-config.el]] sets the notes directory and uses visible-line numbering in Org buffers so folded text does not contribute hidden lines to the count. Org starts in editing view: proportional prose with monospace code and tables, with hidden markup revealed at the text cursor. The =SPC m v= view menu offers:

| Key | Action                                           |
|-----+--------------------------------------------------|
| e   | Editing: mixed pitch, markup at cursor, editable |
| r   | Reading: mixed pitch, hidden markup, read-only   |
| s   | Source: monospace, visible markup, editable      |
| m   | Toggle mixed pitch                               |
| h   | Toggle revealing hidden markup at the cursor     |
| w   | Toggle read-only                                 |

Selecting a preset resets these options; individual toggles adjust the buffer. Source view also disables Org Modern decorations and image/LaTeX previews. Markdown retains its direct =SPC m v= mixed-pitch toggle. The read-only toggle is the same command as =SPC t r=. Doom's =SPC t v= Visible mode reveals all invisible text rather than only markup at the cursor; selecting an Org view turns it off. Wrapping (=SPC t w=), line numbers (=SPC t l=), centring (=SPC t o=), padding (=SPC t P=), Zen and slides remain separate controls. The directory must be configured before Org loads.

#+begin_src emacs-lisp
(load! "lisp/org-config")
#+end_src

* Python environments and language server
[[file:lisp/python-config.el][python-config.el]] repairs Conda environment switching and refreshes Python LSP after environment changes. It also enables Pyright to inspect library source when type information is unavailable. These settings remain deferred until their respective packages load.

#+begin_src emacs-lisp
(load! "lisp/python-config")
#+end_src

* Time popup
[[file:lisp/time-popup.el][time-popup.el]] provides the local and world clock, its popup behaviour and the =SPC t t= binding. Graphical Emacs uses a centred child frame; terminal Emacs uses a bottom popup.

#+begin_src emacs-lisp
(load! "lisp/time-popup")
#+end_src

* Formatting

(load! "lisp/format-config")
#+end_src

* Terminals
[[file:lisp/terminal-config.el][terminal-config.el]] configures Ghostel's Docker shell selection and terminal-specific display settings. Its shell lookup uses the remote user's ID and retains a fallback for containers without a suitable login shell.

#+begin_src emacs-lisp
(load! "lisp/terminal-config")
#+end_src

* Browsing
[[file:lisp/browsing-config.el][browsing-config.el]] makes EWW open in a normal window instead of a bottom popup. The rule also covers buffers renamed to the loaded page's title.

#+begin_src emacs-lisp
(load! "lisp/browsing-config")
#+end_src

* Dictionary lookup
[[file:lisp/lookup-config.el][lookup-config.el]] displays dictionary results in a bottom popup, consistently across repeated lookups. This covers macOS Dictionary, all =define-word= services and offline WordNet through WordNut. Online definitions use a dedicated dictionary buffer rather than the shared evaluation output buffer.

#+begin_src emacs-lisp
(load! "lisp/lookup-config")
#+end_src

* Git
[[file:lisp/magit-config.el][magit-config.el]] enables visible-line relative numbers in Magit buffers for counted Evil motions such as =5j= and =3k=. Folded section contents do not contribute hidden lines to the count; =TAB= toggles the current section. Counted upward motions repeat single visible-line steps to avoid an Emacs 29 off-by-one movement at folded section boundaries. Use =D /= in Magit to filter changes by directory. Selecting the repository root removes the filter. Use =D C= to clear active and remembered file filters. Commit-age annotations respect Magit's margin visibility setting, so Olivetti's outer padding cannot expose disabled annotations.

#+begin_src emacs-lisp
(load! "lisp/magit-config")
#+end_src

* Remote access
[[file:lisp/tramp-config.el][tramp-config.el]] includes the remote connection's own PATH in TRAMP's search paths so tools such as micromamba can be discovered. This applies to Docker and SSH connections.

#+begin_src emacs-lisp
(load! "lisp/tramp-config")
#+end_src

* PDF viewing
[[file:lisp/pdf-config.el][pdf-config.el]] fits PDF pages vertically when opening them with PDF Tools.

#+begin_src emacs-lisp
(load! "lisp/pdf-config")
#+end_src

* Buffer centring
[[file:lisp/olivetti-config.el][olivetti-config.el]] centres visible file, Dired and shell buffers and manages their borders. Centring is disabled whenever windows are side by side, including terminal and sidebar windows, and returns when those splits are closed. Doom popup buffers, PDF viewers and the clock popup are excluded. Full terminal buffers (=SPC o T=) can be centred; terminal popups (=SPC o t=) keep their normal width. Use =SPC t o= to toggle this behaviour.

#+begin_src emacs-lisp
(load! "lisp/olivetti-config")
#+end_src
